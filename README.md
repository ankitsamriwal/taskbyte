# TaskByte

A clean, modern team task tracker - draft version.

- Kanban board (To Do / In Progress / Completed) with drag-and-drop
- Configurable completed-task visibility
- Detailed views by owner, by customer, and by task type
- Custom task types, owners and customers
- Notification settings (recipient emails + events) and a daily report configuration - sending stubbed for the draft
- All data lives in the browser (localStorage)
